# 2 整体情况（技术向总览，仅架构与关键链路，不含具体接口）

## 2.1 技术目标与系统边界

### 2.1.1 两大工作空间与访问边界（技术视角）

从“鉴权入口、路由隔离、数据隔离”角度定义平台后台与租户工作区的边界：平台后台仅处理平台级元信息；租户工作区承载建模/Flow/报表/设置全链路。

### 2.1.2 V1 范围内模块与能力分层

以技术实现落点描述 V1 必须覆盖的模块：多租户与平台后台、租户工作区壳、Modeling、Flows、Reports（Dataset/Chart/Dashboard）、权限与统一 DSL、LLM 辅助。

## 2.2 总体技术架构（逻辑分层）

### 2.2.1 分层架构图（逻辑组件）

说明：前端（平台后台/租户工作区）、API 层、领域服务层（租户/权限/资源树/建模/Flow/报表/审计）、执行与调度（FlowRun）、存储层（元数据存储 + 租户业务数据存储）、外部依赖（外部 MySQL/HTTP/文件、LLM(ollama)）。

### 2.2.2 元数据与业务数据的边界

阐明两类数据：

* 元数据：租户、成员、角色、权限、资源树、表结构、Flow 定义、Dataset/Chart/Dashboard 配置、审计记录；
* 业务数据：租户内建模生成的物理表数据、Dataset 物化表数据、Flow 产出的写入结果。

## 2.3 多租户隔离的技术约束（全链路）

### 2.3.1 数据隔离（tenant_id 强制）

定义所有与业务数据相关表必须包含 tenant_id；所有读写必须带 tenant_id 条件；禁止跨租户 JOIN/写入。

### 2.3.2 访问路径隔离与租户上下文

定义“用户属于租户 + 租户状态 ACTIVE”的双重校验；租户停用后禁止访问并停止调度触发。

# 3 全局规范（只写规则，不写实现）

## 3.1 统一响应与错误语义规范

### 3.1.1 认证/权限失败语义

统一 401（未登录/Token 失效）与 403（已登录但权限不足）的返回语义与前端提示口径。

### 3.1.2 业务错误分类与错误码规则

统一错误码命名、模块前缀、可恢复/不可恢复分类与返回内容最小集（message、定位信息、可读原因）。

## 3.2 多租户隔离规范（规则层）

### 3.2.1 tenant_id 强制规则

任何涉及租户数据的读写必须具备 tenant_id 条件；任何可能跨租户的查询路径视为严重缺陷。

### 3.2.2 租户停用规则

SUSPENDED 时禁止进入工作区、停止调度触发；恢复后行为一致。

## 3.3 统一 FilterDSL 规范（语法与约束）

### 3.3.1 DSL 结构与操作符白名单（规则）

定义 JSON 的字段、类型、允许的操作符、AND/OR 组合方式、字段白名单机制（仅规则，不含解析实现）。

### 3.3.2 DSL 安全与可移植性规则

禁止 SQL 片段注入；禁止引用不存在字段；版本化与向后兼容要求。

## 3.4 数据一致性与并发控制规范

### 3.4.1 写入幂等与重复提交规则

定义创建/更新/删除类操作的幂等策略口径与冲突语义（例如基于版本号/更新时间的乐观锁规则）。

### 3.4.2 引用保护与级联规则

任何删除必须先做依赖检查并给出依赖列表；不得隐式级联删除导致资产丢失。

## 3.5 审计规范（规则层）

### 3.5.1 必须审计的事件范围

权限变更、建模结构变更、Flow 定义/调度/运行关键事件、报表资产关键变更必须可追溯（仅规则）。

### 3.5.2 审计记录字段最小集

操作者、时间、对象、动作、结果、失败原因、变更摘要（before/after）等字段口径。

### 6.2.1 能力边界

统一承载：过滤（FilterDSL）、排序、分页、聚合/选择、导出；并作为 Modeling 表数据页、Dataset/Chart 查询、Dashboard 渲染等共同底座。

### 6.2.2 权限叠加

资源级权限前置校验；查询中强制叠加 RowPermission；返回/更新强制执行 ColumnPermission。

### 6.2.3 执行安全

字段白名单、最大行数/超时、导出限流、慢查询保护、拒绝不安全表达式。

## 6.3 FilterDSL（解析、验证、编译）

### 6.3.1 解析与校验实现

### 6.3.2 编译到查询表达式

将 DSL 编译为底层查询条件（抽象层，不绑定具体数据库方言的扩展点）。

## 6.4 LLM 辅助（编码生成）

### 6.4.1 接入方式与可用性

对接本地 ollama；失败降级为手工输入；审计与滥用保护。

### 6.4.2 命名规范与重复检测
